# Structure métier inspect-san (8 tables + clés techniques auxiliaires)

## Tables métier

### ProduitUtilise
- CodeProduit (PK, int auto-incrémenté)
- LibeleProduit (varchar, NOT NULL)

### OutilUtilise
- CodeOutile (PK, int auto-incrémenté)
- LibelleOutile (varchar, NOT NULL)

### Categories
- CodeCategories (PK, int auto-incrémenté)
- Designation (varchar, NOT NULL)
- Valeurs seed : Collège, Complexe scolaire, Groupe scolaire, EP, Lycée, Institut, École

### Etablissement
- NumAgrement (PK, varchar)
- Id (varchar, UNIQUE, NOT NULL) — clé technique (FK AspNetUsers.EcoleId, liens internes)
- IDDinacope (varchar, UNIQUE, NOT NULL)
- RegGes (varchar, NOT NULL) — constante RegGes
- SousDivision (varchar, NOT NULL) — constante SousDivision
- Denomination, AdresseEtablissement, NumNotification
- MatriculeChef (FK → ChefEtablissement.Matricule, nullable)
- CodeCategories (FK → Categories.CodeCategories, int)

### ChefEtablissement
- Matricule (PK, varchar) — saisi manuellement
- NomComplet, Telephone
- AnneeDebutActivite (int, nullable) — année de début d'activité
- Les établissements référencent le chef (pas l’inverse)

### Mission
- NumOrdre (PK, varchar)
- Id (varchar, UNIQUE, NOT NULL) — clé technique (Photos.FicheControleId)
- DateDebut, DateFin, NbreBatiment, EtatBatiment
- NbrToiletteFille, NbrToiletteGarcon, NbrEleve
- NbreProduit (int), CodeProduit (FK → ProduitUtilise, int nullable) — résumé / 1er produit
- NbreOutil (int), CodeOutil (FK → OutilUtilise.CodeOutile, int nullable) — résumé / 1er outil
- Observation, Validite (statut mission), NumAgrement (FK Établissement)
- MontPer (decimal) — montant perçu
- StatutFiche, NomEquipe, Objet, SigneLe, SignePar
- ProduitsAutres, ProduitsAutresQuantite
- OutilsAutres, OutilsAutresQuantite — libellé libre hors référentiel (comme produits)
- RecommandationPreliminaire, ValideePar, ValideeLe, CreatedAt

### MissionProduit (liaison multi-produits)
- Id (PK auto-inc), NumOrdre (FK Mission), CodeProduit (FK ProduitUtilise), Quantite

### MissionOutil (liaison multi-outils)
- Id (PK auto-inc), NumOrdre (FK Mission), CodeOutil (FK OutilUtilise.CodeOutile), Quantite

### Agents
- MatrAgent (PK, varchar) — saisi manuellement
- NomAgent, TelAgent

### Decision
- NumDecision (PK), DecisionFin, NumOrdre (FK Mission), NumAgrement (FK Établissement)
- DecisionFin = DecisionTypes.* :
  - suspension_temporaire_chef
  - rehabilitation
  - fermeture_temporaire

### Affectation
- IdAffectation (PK auto-inc)
- NomOrdre (FK Mission.NumOrdre)
- MatrAgent (FK Agents)
- Fonction (varchar, NOT NULL) — RolesMissionCodes.* (chef_equipe, chef_adjoint, membre)
- EcritureDeleguee (bool, défaut false) — délégation d'écriture chef d'équipe → adjoint

## Paramètres UI
- RefCategories : categories, produits, outils
- Création : saisie du libellé uniquement ; code = auto-incrément BDD

## Notes
Regimes, Sousproveds → constantes | Produits → ProduitUtilise | Ecoles → Etablissement
Pas de colonne Id séparée sur ProduitUtilise / OutilUtilise / Categories : le Code* EST la PK auto-inc.
État toilettes supprimé : seul EtatBatiment est conservé sur Mission.
